# Серия 1 — «Ты уверен, что она спит?»

Вертикальное видео 1080×1920, 30 fps, **114,6 с** (обрыв в чёрный на 113,6 с).
Стиль по референсам: плоская векторная 2D-графика, ночная сине-фиолетовая палитра,
свечение экранов, свет через жалюзи, тёплый флешбэк. Субтитров и надписей нет:
на экране только часы `02:17` и текст уведомлений.

## Файлы

| файл | что это |
|---|---|
| `../output/episode1.mp4` | готовое видео: картинка, музыка и эффекты, **без голоса** |
| `../output/bed.wav` | отдельная дорожка музыки и эффектов |
| `voice_lines.json` | все реплики с тайм-кодами (диктор, её фраза, шёпот) |
| `mix_voice.py` | сводит озвучку с видео, когда она будет готова |
| `anim.js`, `index.html` | анимация: 26 сцен, функция `render(t)` |
| `render.js` | рендер кадров через Playwright и ffmpeg |
| `audio.py` | процедурная музыка и эффекты |

## Озвучка (когда появятся токены ElevenLabs)

1. Сгенерируй каждую реплику из `voice_lines.json` отдельным файлом и назови её по `id`:
   `episode1/voice/01.mp3` … `26.mp3`.
   * диктор: мужской голос, спокойный, с тревогой, паузы на «…» и «—»;
   * `09` (`her`): её фраза, тихо и спокойно;
   * `14` (`her_whisper`): шёпот. Скрипт сам приглушит его, как будто он звучит из-за двери.
2. `python3 episode1/mix_voice.py` — получится `output/episode1_voiced.mp4`.
   Скрипт поставит реплики на тайм-коды, приглушит музыку под голос и предупредит,
   если какая-то реплика не помещается в свой слот.
3. Самая плотная реплика — последняя (`26`): на неё 4,8 с до обрыва.

## Пересборка

```bash
cd episode1
node render.js ../output/video_only.mp4 30 4     # картинка (~10 мин на 4 ядрах)
python3 audio.py ../output/bed.wav               # музыка + эффекты
ffmpeg -i ../output/video_only.mp4 -i ../output/bed.wav -c:v copy -c:a aac -b:a 192k -shortest ../output/episode1.mp4
node preview.js /tmp/sheet.png 5 30 62 81 107    # контактный лист любых моментов
```
