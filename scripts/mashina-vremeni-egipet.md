# «Машина времени: Египет» — сериал для TikTok/Shorts

**Формат:** вертикаль 9:16, 3 серии по ~110 сек, закадровый голос от второго лица («ты»).
**Стиль (как в референсе):** плоская 2D-векторная графика, тёмная палитра + один акцентный цвет (там красный — тут **золото/песок + бирюза**), крупные субтитры по 2–4 слова, ключевое слово выделено цветом, таймер в левом верхнем углу, карточки «ПРАВИЛО N», схемы-карты сверху, счётчик сверху справа, клиффхэнгер «2 ЧАСТЬ СКОРО!».

**Что берём из референса:**
- Хук в первые 2 сек: цифра/таймер на весь экран.
- Зритель = герой («ты»). Каждые 10–15 сек — новое правило выживания или поворот.
- Реальные детали придают правдоподобие (там — терминал, эскалатор; у нас — реальная история Тутанхамона).
- Обрыв на самом интересном.

**Таймер серии:** вместо часов — «ГОД 1323 ДО Н.Э.» и обратный отсчёт до запечатывания гробницы.
**Счётчик справа сверху:** «ЗАРЯД 3%» машины времени (растёт/падает по сюжету).

Темп озвучки ≈ 2,3 слова/сек → ~250 слов на серию.

## Заметки по исторической основе
- Тутанхамон похоронен ~1323 до н.э. в Долине Царей; гробницу открыл Говард Картер в 1922 г.
- Визирь Эйе действительно стал фараоном после Тутанхамона.
- Дейр-эль-Медина — реальная деревня строителей царских гробниц.
- Грабителей гробниц в Египте действительно казнили, в т.ч. сажали на кол.
- Гробницу Тутанхамона в древности частично грабили — дважды, вскоре после похорон, — это обыгрываем через «ход грабителей».
- Роспись с «человеком со светом» — вымысел для клиффхэнгера.
